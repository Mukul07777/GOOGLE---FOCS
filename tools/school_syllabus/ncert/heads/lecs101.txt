These occur when there are syntax errors, runtime errors or logical errors in the code. In Python, exceptions are errors that get triggered automatically. However, exceptions can be forcefully triggered and handled through program code. In this chapter, we will learn about exception handling in Python programs. 1.2 Syntax Errors Syntax errors are detected when we have not followed the rules of the particular programming language while writing a program. These errors are also known as parsing errors.
